## Описание

В данной работе на страницу добавлен внешний скрипт `script.js`, реализующий анализ массива экспериментальных данных с использованием базовых конструкций JavaScript.

## Что реализовано

- **Ввод и вывод данных:** запрос имени через `prompt`, приветствие и итоговый результат через `alert`, детальный лог вычислений через `console.log`.
- **Функции:** реализованы отдельные функции для поиска максимума (`findMax`), минимума (`findMin`), подсчета суммы (`calculateSum`), фильтрации значений выше среднего (`filterAbove`) и подсчета аномалий (`countAnomalies`).
- **Циклы и условия:** использованы циклы `for` для обхода массива и условные конструкции `if` для проверки порога аномалий (<= 10% от максимума) и оценки разброса данных.
- **Дополнительная логика:** если разброс данных (max - min) превышает 50, в консоль выводится сообщение о высокой вариативности данных.

## Запуск

1. Откройте `index.html` в браузере или через GitHub Pages.
2. Нажмите кнопку «Запустить анализ данных» в разделе «О себе».
3. Введите имя в появившемся окне и нажмите ОК.
4. Просмотрите всплывающие окна с результатами.
5. Откройте консоль разработчика, чтобы увидеть детальный лог вычислений и сообщение о вариативности данных.
